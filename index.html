WallConnectorLog

A native iPhone companion to your own WallConnectorLog server.

WallConnectorLog the server logs your Tesla Wall Connector Gen 3 around the clock — the charger itself keeps no history. The app gives that log an interface built for the phone: live charger status, the real charge sessions the server has derived, and the charger's lifetime counters.

It talks only to a server you run yourself. It never connects to Tesla, there is no account to create, no service in between, and nothing leaves your network.

WallConnectorLog is a sibling of EVLog, the same developer's TeslaMate companion — one app for the car, one for the charger, built the same way: your own server, no accounts, no cloud. The two share a support address.

The app is in development and not on the App Store yet. It is free and open source under the MIT licence — no ads, no in-app purchases, no analytics. The source code is on GitHub, and with no server configured it runs in a built-in demo, so there is something to look at before there is anything to connect to.

What you need

  • A running WallConnectorLog server — two files, docker-compose.yml and .env, are the whole install
  • The server reachable from your phone, by default on port 4680
